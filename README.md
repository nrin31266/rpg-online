# Huyền Lộ

[Tài liệu thiết kế](docs/design/README.md) là nguồn luật và routing của dự án. [Game mẫu](prototypes/VS1_EndToEnd/README.md) là Unity project disposable dùng thử gameplay/UX và debug nhanh.

```text
docs/design/                 GDD, Technical, Analysis, Art, Roadmap
prototypes/VS1_EndToEnd/      Unity project mẫu + evidence theo revision
research/                    source/ghi chú tham khảo
```

Production chưa bắt đầu. Dự kiến `game/` là Unity project cho Client và Dedicated builds với gameplay chung; `backend/` là Spring Boot/PostgreSQL. Các folder/codebase đó chưa được scaffold. Không dùng cấu trúc prototype làm architecture authority.
